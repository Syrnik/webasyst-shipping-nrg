# ТК Энергия — плагин доставки для Webasyst

Плагин рассчитывает стоимость доставки заказа транспортной компанией
[«Энергия»](https://nrg-tk.ru/).

Для расчёта используется открытое API v2 ТК «Энергия», ключи доступа и регистрация не нужны.

## Возможности

- Расчёт доставки «до двери» и «до терминала».
- Учёт габаритов отправления: габариты, рассчитанные приложением (Shop-Script), или средние размеры из настроек.
- Учёт сроков комплектации Shop-Script — покупатель видит ориентировочную дату доставки.
- Наценка на доставку: фиксированная сумма, процент или формула.
  В формуле доступны переменные `Z` (стоимость заказа) и `S` (рассчитанная стоимость доставки),
  например `Z*0.025+S+100` или `Z*0.1+S^2`.
- Порог бесплатной доставки отдельно для доставки «до двери» и «до терминала».
- Оптимизатор тарифа — показ только самого дешёвого варианта.
- Скрытие метода доставки для недоступных городов.

## Ограничения

Расчёт выполняется только для отправлений внутри России.

## Требования

- PHP 7.4 или новее
- Webasyst Framework 4.3 или новее

## Установка

Плагин распространяется через [Магазин Webasyst](https://www.webasyst.ru/store/plugin/shipping/nrg/).
